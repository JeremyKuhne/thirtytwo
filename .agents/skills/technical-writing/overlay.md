# Technical writing overlay

Repository-specific bindings for thirtytwo.

- For pull request prose, follow the
  [pull request template](../../../.github/PULL_REQUEST_TEMPLATE.md) and the
  [contribution guidance](../../../CONTRIBUTING.md#submitting-changes): explain
  the behavior and report validation from the current diff and command output.
- Settle source-code readability with
  [code-comprehension](../code-comprehension/SKILL.md), agent customization
  correctness with [agent-files-review](../agent-files-review/SKILL.md), and
  code/test claims with [pre-pr-self-review](../pre-pr-self-review/SKILL.md)
  before the final prose pass.
